Install

Four steps. No build tools.

  1. 1

    Install a userscript manager

    Use Tampermonkey, Violentmonkey, or Userscripts on Safari.

  2. 2

    Open the install URL

    Click Install on the userscript screen. GitHub Pages serves the current routecraft.user.js directly.

  3. 3

    Open your API docs

    Swagger UI, Redoc and FastAPI /docs pages are detected automatically.

  4. 4

    Press Alt+Shift+S

    Open the overlay from any page. Esc closes it. Browse, authorize and send without leaving the page.

What you get

Docs and requests in one place.

  • OpenAPI 2.0, 3.0 and 3.1 JSON or YAML from a URL, file or pasted text, with recursive $ref resolution.
  • Swagger UI-style Try it out Enable an operation, fill its inputs, then Execute. Path, query, header and cookie parameters, request bodies, auth and response inspection.
  • Response examples and schemas Pick a media type and switch between Example Value and Schema for every declared response.
  • Zero-CORS transport GM_xmlhttpRequest reaches localhost and APIs that do not send CORS headers.
  • Auth and history Bearer, Basic, API key, OAuth 2.0 and OpenID Connect, plus replayable request history.
  • Code generation cURL, fetch, Axios, Python, Go, PHP, Ruby, Java, C#, HTTPie and PowerShell.
  • Quiet interface Swagger UI-style docs, light/dark themes, responsive layout and keyboard send.
